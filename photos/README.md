# Adding photos

Officers: the easiest way is the Site Editor (`/admin.html` on the live site) → **Photos** tab. Photos are shrunk automatically and can be deleted from the same place.

Manual alternative: open this folder on github.com → **Add file → Upload files** → drag in JPG/PNG images → **Commit changes**. About a minute later a GitHub Action makes thumbnails, shrinks oversized originals, and updates the gallery.

Notes
- Photos show newest first by filename, so a leading date (`2026-10-04-…jpg`) keeps them in order. The editor names files this way for you.
- The gallery shows photos without captions.
- Don't put anything in `thumbs/`; it's regenerated every time. `people/` holds officer headshots for the Leadership page and is not shown in the gallery.
- Only upload photos of people who are happy to appear on the public site.
