# Adding photos

1. Open this folder on github.com.
2. Click **Add file → Upload files**, drag your JPG/PNG/WebP images in, and click **Commit changes**.
3. Wait about a minute. A GitHub Action makes thumbnails, shrinks oversized originals, and updates the gallery on the Photos page automatically.

Tips
- Name files descriptively, e.g. `2026-10-04-nec-tournament-podium.jpg`. The gallery turns that into the caption "Nec tournament podium". Newest filenames (sorted alphabetically) show first, so a leading date keeps things in order.
- For a custom caption, add a line to `captions.txt` in this folder: `filename.jpg | Your caption here`.
- Don't put anything in `thumbs/`; it's regenerated every time.
- Please only upload photos of people who are happy to appear on the public site.
