# Harvard Combat Sports Club — website

Static site for HCSC (Brazilian Jiu-Jitsu + Women's Wrestling). No build step, no framework: plain HTML/CSS/JS, hosted on GitHub Pages behind Cloudflare DNS. Anyone on the e-board with GitHub access can update it from a browser.

## Editing content (no coding needed)

| To change…                      | Edit this file                          |
|---------------------------------|-----------------------------------------|
| Practice times / locations      | `data/schedule.json`                    |
| E-board, coaches, roles, photos | `data/leadership.json`                  |
| Email, WhatsApp link, dues      | `data/site.json`                        |
| Disciplines (name, color, Instagram, page) | `data/branches.json`         |
| Photo gallery                   | Upload images to `photos/` (see `photos/README.md`) |
| FAQ questions                   | `faq.html` (copy an existing `<details>` block)     |
| Page text                       | The matching `.html` file               |
| Colors / fonts                  | The `:root` tokens at the top of `assets/style.css` |
| Logo                            | Drop the official Club Sports shield in `assets/` and point `"logo"` in `data/site.json` at it (e.g. `assets/shield.png`). Also update the `<link rel="icon">` in each page if you want it as the favicon. |

On github.com: open the file → pencil icon → edit → **Commit changes**. GitHub Pages redeploys in about a minute.

### Schedule format
```json
{ "day": "Tuesday", "start": "5:30 PM", "end": "7:30 PM", "branch": "Jiu-Jitsu", "location": "QRAC" }
```
`branch` must match a discipline's `name` or `short` in `branches.json` (that's where its color comes from). `location` must match a key in `locations`. Update `term` each semester.

**Cancelling a single practice** (holiday, tournament, room conflict) — add to `cancellations`; the site strikes it through in the week view and skips it in "Next practice":
```json
{ "date": "2026-11-26", "branch": "Jiu-Jitsu", "note": "Thanksgiving" }
```
Leave out `branch` to cancel everything that day. Old entries are harmless; prune them whenever.

**Announcement banner** on Home and Schedule — set `announcement.text` and an `until` date (it hides itself after that). Empty text = no banner.

### Leadership format
```json
{ "name": "Jane Doe", "year": 2028, "role": "Co-President", "photo": "photos/people/jane.jpg", "bio": "" }
```
`role`, `photo`, and `bio` are optional. Headshots go in `photos/people/` (that subfolder is ignored by the gallery script).

## Adding a discipline (Muay Thai, MMA, …)

Everything discipline-specific is generated from `data/branches.json`: the nav link, the card on the home page, the footer link, Instagram buttons, schedule colors, and the "Disciplines" count on the About page. Adding a sport is three steps:

1. **`data/branches.json`** — add an entry:
   ```json
   { "id": "muay-thai", "name": "Muay Thai", "short": "Muay Thai", "nav": "Muay Thai",
     "page": "muay-thai.html", "tagline": "Striking fundamentals, pad work, and conditioning.",
     "eligibility": "Open to all", "color": "#1f4e79", "instagram": "hcsc_muaythai", "active": true }
   ```
   (`active: false` keeps a discipline hidden while you're setting it up — there's already a hidden Muay Thai stub in the file to start from.)
2. **Page** — copy `branch-template.html` to `muay-thai.html`, set `data-branch="muay-thai"` on `<body>`, and replace the bracketed text.
3. **`data/schedule.json`** — add sessions with `"branch": "Muay Thai"` (must match the `name` or `short` in branches.json) and, if needed, a new entry in `locations`.

Nothing else changes. Retiring a discipline is `active: false`.

## Pages
`index.html` Home · `about.html` · `jiu-jitsu.html` · `wrestling.html` (one page per discipline; `branch-template.html` for new ones) · `schedule.html` · `leadership.html` · `faq.html` · `photos.html` · `join.html` (join, dues, financial aid, donate, contact) · `404.html`

The header, nav, and footer are generated by `assets/site.js` so they only need to be edited once. The Harvard student-organization disclaimer lives in `renderFooter()` there.

## Running locally
The pages load JSON with `fetch`, so open them through a local server rather than double-clicking:
```bash
python3 -m http.server 8000     # then visit http://localhost:8000
```

## Deploying: GitHub Pages + Cloudflare

### 1. GitHub
1. Create a repo (e.g. `harvard-combat-sports/website`), push these files to the `main` branch.
2. **Settings → Pages → Build and deployment**: Source = *Deploy from a branch*, Branch = `main`, folder = `/ (root)`. Save.
3. The site is live at `https://<org>.github.io/<repo>/` within a minute. (Absolute links in `404.html` assume a custom domain at the root; everything else uses relative paths and works either way.)
4. **Settings → Actions → General → Workflow permissions**: choose *Read and write permissions* so the photo workflow can commit.

### 2. Domain
Pick and register the domain (Cloudflare Registrar sells at cost). Harvard's Trademark Program requires DSO/Trademark clearance before using "Harvard" in a domain name and asks that Harvard-named domains be registered to the President and Fellows of Harvard College — check with the Club Sports Office before buying `harvard…` anything. A name like `hcsc.club` / `hcscgrappling.org` avoids the issue.

### 3. Cloudflare DNS
In the Cloudflare dashboard for the domain, **DNS → Records**, add:

| Type  | Name  | Content                 | Proxy |
|-------|-------|-------------------------|-------|
| A     | `@`   | `185.199.108.153`       | DNS only (grey cloud) |
| A     | `@`   | `185.199.109.153`       | DNS only |
| A     | `@`   | `185.199.110.153`       | DNS only |
| A     | `@`   | `185.199.111.153`       | DNS only |
| CNAME | `www` | `<org>.github.io`       | DNS only |

Leave proxying off (grey cloud) at least until GitHub has issued its certificate; you can turn the orange cloud on afterwards if you want Cloudflare caching, with SSL mode set to **Full**.

### 4. Connect the domain to Pages
1. **Settings → Pages → Custom domain**: enter `www.yourdomain.org` (GitHub recommends the `www` form and will redirect the apex). Save; GitHub writes a `CNAME` file to the repo.
2. Wait for the DNS check to pass, then tick **Enforce HTTPS**.
3. Optionally verify the domain under your GitHub org/user **Settings → Pages → Verified domains** so nobody else can claim it.

### 5. Hand-off checklist
- [ ] Add the official Club Sports shield to `assets/` and set `"logo"` in `data/site.json` (get the file and permission from the Club Sports Office).
- [ ] Confirm "Harvard Combat Sports Club" / "HCSC" is the approved name and that the footer wording satisfies the Club Sports Office media policy.
- [ ] Fill in officer roles and coaches in `data/leadership.json`.
- [ ] Upload the first batch of photos.
- [ ] Give at least two officers admin access to the GitHub repo and the Cloudflare account so the site survives graduation.

## Harvard compliance notes
- Footer on every page identifies HCSC as an officially recognized student organization of Harvard College and a student-run club sport, and carries the trademark acknowledgement (Trademark Program, *Use of Harvard Names and Insignias in Electronic Contexts*).
- No third-party advertising or sponsor endorsements are on the site; Harvard's commercial-activities principles prohibit them on student-org pages. If sponsors are ever added, clear it with the Club Sports Office first.
- Merchandise with the Harvard name needs Trademark Program approval; keep any future "Gear" page to order forms rather than a public storefront until cleared.
